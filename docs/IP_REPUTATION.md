# IP 來源、計分與隱私

Guard 將這項功能稱為「IP 風險（純淨度參考）」。這是公開資料的參考指標，不是 Anthropic 的判定，也不是封號、洩漏或詐騙機率。低分無法保證家用線路、存取資格或帳號安全。

## 來源

依 2026-11-03 官方說明整合，未內建 API 金鑰：

| 來源 | 使用內容 | 限制與官方說明 |
| --- | --- | --- |
| IPQuery | `risk_score` 與 VPN、代理、Tor、資料中心、行動網路標記 | 分值是指標組合，不是機率；未標記不代表安全。[資料來源及方法](https://ipquery.io/sources)、[代理資料說明](https://ipquery.io/data/proxy) |
| ProxyCheck | v2 的 `risk`、代理標記、網路類型及歸屬 | 匿名額度為每天 100 次，可能與同出口使用者共享；v2 支援至 2035 年。[API 與配額](https://proxycheck.io/api/) |
| ipapi.is | 匿名回傳的 IP、國家及 ASN 歸屬 | 2026-09-01 起匿名查詢不含 VPN／代理等偵測資料，不納入評分；匿名每天 30 次。[匿名層說明](https://ipapi.is/free-tier.html) |

展開「查看來源」可見每個網站的返回狀態、原始分值、已回傳的標記、歸屬與官方說明連結。Guard 不假設不同資料庫完全獨立，來源互相矛盾時仍保留各自結果。資料歸各來源所有；IPQuery 的底層資料署名與條款詳見其官方來源頁。本工具只呈現必要的正規化欄位，不散發底層資料庫。

## 顯示方式

- 三個來源並行查詢；每個結果到達便更新，不等待最慢來源。每個來源最多等待約 7 秒。
- 已返回有效分值取最高值，並依使用者介面刻度顯示為 1–100%；來源原始 0 分對應顯示 1%，展開仍可看到原始 0 分。
- 1% 為綠色、100% 為紅色，中間連續漸變。少於兩個含評分來源時標註資訊有限；無有效評分、停用或過期時顯示灰色「未確認」等狀態。
- 失敗、額度耗盡及僅歸屬資料均不補成 0 分，也不依標記自行編造分值。評分不參與自動放行決策。
- 守護執行期間約每小時重新整理，並合併進行中的重複請求。可手動重新整理，或於出口變更時查詢新 IP；這些操作會額外消耗來源配額。Claude 退出後停止定期查詢，畫面可保留帶時間的歷史結果。

## 網路與隱私

啟用後將出口 IP 作為查詢參數送往上述三個服務，服務也能觀察查詢的來源出口。使用者可在設定取消勾選「啟用公開 IP 來源檢查」。本機 DNS／WebRTC 檢查仍維持原有的本機範圍。

請求使用 HTTPS 憑證驗證，固定經 Guard 已確認的受控轉發路徑（系統網路／系統代理或舊版專用核心），沒有直連降級或重新導向。連線暫停時，Guard 只允許這些診斷查詢使用私有核心；Claude 的受控閘門仍關閉。來源延遲或失敗不會額外暫停 Claude，也不會解除已存在的暫停。

不提交 Claude 帳號、聊天內容、裝置指紋或 VPN 訂閱。僅將必要的結果及時間寫入私人 Runtime 快取／事件記錄，不保存完整 API 回應或精確座標。分享診斷資料前仍需移除 IP 等個人資訊。

## IP 變更與確認

1. 出口變更時先關閉受控連線，選單列提示顯示新 IP，來源結果逐個補上；查不到評分也不會自動放行。
2. 點選「確認新 IP」才啟動再次核驗。確認綁定本次 IP 與隨機提案識別碼，舊按鈕不能批准另一個出口。
3. 保持原批准國家、節點與保護方式，重新核驗出口、節點設定，以及增強模式的 LuLu 狀態；目前 TUN／非 TUN 模式另行顯示，TUN 關閉本身只提醒。通過後才原子保存新 IP、更新基準並恢復受控連線。
4. 核驗期間再次切換網路、出口再變、設定改動或過濾失效時保持暫停。地區或節點變更須退出 Claude 並完整重新設定。純檢查會話確認後也不會自行啟動 Claude。

以上是受控連線的保護流程，不保證所有程式及本機回環例外均受控。偵測時間仍受輪詢間隔、請求耗時與系統排程影響。
